# Pablo Nimo · Formación para centros

Web profesional en galego para presentar a oferta de formación práctica en centros educativos:

- intelixencia artificial aplicada á aula e ao centro;
- radio escolar ao servizo da realidade de aula;
- cortadora láser como servizo interno do centro;
- arquivo dinámico da formación impartida;
- proxectos públicos, formatos de colaboración e contacto.

Os datos do histórico proceden das evidencias conservadas no proxecto profesional. As imaxes de recurso xeradas están identificadas na propia web.
